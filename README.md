# C Programming Feedback System

## About
A beginner-friendly C programming project that demonstrates file handling using write, append, and read modes.

## Features
- Collects 5 feedback points about C programming.
- Collects 5 feedback points about the C programming teacher.
- Writes feedback using write mode (`w`).
- Adds teacher feedback using append mode (`a`).
- Reads and displays the complete feedback report using read mode (`r`).

## Technologies Used
- C Programming
- File Handling
- VS Code

## Files
- `project_5.c` — Source code.
- `feedback.txt` — Sample feedback output.

## How to Run
```bash
gcc project_5.c -o project_5
./project_5
```

On Windows, run `.\project_5.exe` after compilation.

## Learning Outcome
Learned how to create, write, append, read, and close files in C.
